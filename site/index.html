What you can do

Sign

PDF (PAdES B-B to B-LTA), any file (CAdES) or XML (XAdES), with visible stamps and timestamps.

Validate

Integrity, signature, certificate chain (ICP-Brasil included), revocation and timestamps, as Valid, Invalid or Indeterminate.

Inspect

See what is inside a signature: signer, algorithms, PAdES level, timestamps and embedded LTV data.

HTML to PDF

Generate contracts and reports from HTML and CSS (flexbox, grid, fonts, PDF/A) and sign them.
