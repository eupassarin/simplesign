# Migrating from v0.6 to v0.7

## Overview

v0.7.0 introduces **15 service interfaces** extracted across all projects to support **Dependency Injection**. Existing code using the public API continues to work without changes. All constructors preserve fallback defaults.

## What Changed

### New service interfaces (Core)

| Interface | Default implementation | Replaces direct use of |
|-----------|----------------------|----------------------|
| `IOcspClient` | `OcspClient` | `new OcspClient(httpClient, logger)` |
| `ICrlClient` | `CrlClient` | `new CrlClient(httpClient, logger)` |
| `IRevocationChecker` | `RevocationChecker` | `new RevocationChecker(ocsp, crl, logger)` |
| `ITimestampClient` | `TimestampClient` | `new TimestampClient(httpClient, tsaUrl, logger)` |
| `ITimestampClientFactory` | `TimestampClientFactory` | `new TimestampClientFactory(...)` |
| `ICertificateChainService` | `CertificateChainService` | `CertificateChainUtility.LoadCertsFromBytes()` |
| `ICryptoVerifier` | `CryptoVerifierService` | `CryptoVerifier.VerifySignature()` |
| `ICmsParser` | `CmsParserService` | `CmsParser.Parse()` |
| `ITimestampValidator` | `TimestampValidatorService` | `TimestampValidator.ValidateTimestamp()` |

### New service interfaces (PAdES / Pdf)

| Interface | Default implementation | Replaces direct use of |
|-----------|----------------------|----------------------|
| `IPdfSignatureValidator` | `PdfSignatureValidator` | `new PdfSignatureValidator(options)` |
| `IIntegrityVerifier` | `IntegrityVerifierService` | Extracted from validator |
| `ILtvEmbedder` | `LtvEmbedder` | `new LtvEmbedder(...)` |
| `IPdfStructureReader` | `PdfStructureReaderService` | `PdfStructureReader.ReadSignatureFieldsAsync()` |
| `IConformanceDetector` | `ConformanceDetectorService` | `ConformanceDetector.Detect()` |
| `IPdfSignatureInspector` | `PdfSignatureInspectorService` | `PdfSignatureInspector.InspectAsync()` |
| `IPadesExtractor` | `PadesExtractorService` | `PadesExtractor.ExtractFromFileAsync()` |

### New service interfaces (CAdES / XAdES)

| Interface | Default implementation | Package |
|-----------|----------------------|---------|
| `ICadesSignatureValidator` | `CadesSignatureValidator` | `SimpleSign.CAdES` |
| `IXadesSignatureValidator` | `XadesSignatureValidator` | `SimpleSign.XAdES` |

### DI Registration

```csharp
// Registers all services (PAdES + Core + Pdf)
services.AddSimpleSign();

// Country-specific extensions
services.AddSimpleSignBrasil();

// Register CAdES/XAdES services standalone
services.AddSimpleSignCades();
services.AddSimpleSignXades();
```

### CLI DI integration

The CLI now uses `SimpleSignTypeRegistrar` to bridge Spectre.Console to `IServiceCollection`. All commands use constructor injection. This is transparent to users — `simplesign sign`, `simplesign validate`, etc. work identically.

### Breaking changes

**None.** All constructors preserve optional parameters with fallback defaults:

```csharp
// Both work the same:
var validator1 = new PdfSignatureValidator(new ValidationOptions());      // manual
var validator2 = serviceProvider.GetRequiredService<IPdfSignatureValidator>(); // DI
```

### Removed InternalsVisibleTo

The `simplesign` CLI no longer accesses internal APIs from `SimpleSign.Core`, `SimpleSign.Pdf`, or `SimpleSign.PAdES`. Three methods on `SignatureAppearance` were promoted to `public`:

- `WithBackgroundImagePng(byte[] imageBytes)`
- `WithBackgroundImageJpeg(byte[] imageBytes)`
- `WithExtraLines(IReadOnlyList<string> extraLines)`

### New NuGet packages

Two new standalone packages are available:

```bash
dotnet add package SimpleSign.CAdES  # CMS/PKCS#7 detached signatures
dotnet add package SimpleSign.XAdES  # XML-DSig enveloped signatures
```

Both are also included in the `SimpleSign` meta-package.
